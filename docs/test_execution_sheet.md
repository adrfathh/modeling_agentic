## Kriteria Pengisian Kolom

- **Environment**: Staging / UAT / Production.
- **Status**: `Pass` jika Expected Result pada `test_cases.md` terpenuhi sepenuhnya; `Fail` jika tidak sesuai; `Blocked` jika pengujian tidak dapat dijalankan karena dependensi belum siap; `Not Executed` jika belum diuji.
- **Bug ID / Catatan**: Diisi nomor tiket bug (jika ada sistem tracking terpisah) atau catatan singkat penyebab kegagalan.
- **Status Retest**: `Pending` / `Pass` / `Fail` — diisi setelah defect diperbaiki dan diuji ulang.
